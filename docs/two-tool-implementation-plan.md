# Переход к двум инструментам

Дата обновления: 16.10.2026. Ограничитель расходов снят по решению пользователя; стоимость и время измеряются по тестам.

## Первый инструмент: база до рассылки

- [x] Сгруппировать строки контактов по компании, названию и ИНН с сохранением постоянных ID и исходных строк.
- [x] Принимать базу XLSX, её название и фильтры выгрузки, а также текст или документ с предложением отправителя. Снимок предложения фиксируется в запуске.
- [x] Одним вызовом недорогой модели построить широкие группы из реального предложения и слов деятельности, встречающихся в базе. Услуга каждой группы подтверждается дословной цитатой из предложения. Скрипт распределяет компании по описанию из базы; неоднозначное остаётся в «Общем». Предположение о потребности не считается фактом.
- [x] Проверить вакансии на официальных сайтах компаний, попавших в группы. Положительный сигнал требует ссылки на подходящую вакансию. Отсутствие подтверждения нейтрально и не меняет группу. Проверка идёт ограниченными параллельными пакетами и может быть продолжена после паузы.
- [x] Показать в интерфейсе только загрузку, статус, расходы API, группы, компании, найденные вакансии и выгрузку. Старые конвейеры и данные в БД сохранены, но прежний сценарий создания убран с основного экрана.
- [x] Экспортировать исходные строки без потерь: `mailing.xlsx` с ID, группой и сигналом вакансии; файлы групп и исключений; `integration.csv` для сверки.
- [x] Сохранить ручное изменение группы/исключения с причиной; старый экспорт после правки становится недействительным.
- [ ] Измерить качество групп на размеченной выборке, отдельно долю «Общего» и ошибки привязки вакансий. Локальные тесты проверяют механику, но не точность сегментации.
- [ ] Провести небольшой пилот с реальным API и официальными сайтами, затем замерить стоимость и время на масштабируемой выборке. Не экстраполировать по старому конвейеру глубокого исследования.

## Второй инструмент: заинтересованные лиды

- [ ] Принимать ответы и список заинтересованных лидов с постоянными ID первого инструмента.
- [ ] Исследовать конкретные компании только после подтверждения интереса; составлять отчёт с фактами, ссылками, гипотезами и вариантами предложения.
- [ ] Проверить импорт, сопоставление, качество отчётов и стоимость на 5–10 лидах. Этот процесс не пересчитывает первый проход.
