# Первый этап — список работ и результат проверки

Цель: сохранить все строки исходной базы, объединить контакты по предварительной компании и передать следующему этапу опорный ресурс. Этап не определяет потребности компании и не вызывает модель.

- [x] Проверить соответствие исходного XLSX, сохранённых строк и компаний без сетевых или платных запросов.
- [x] Проверить все группы с несколькими строками по доступным ИНН и названиям, а также совпадение сайтов-опор.
- [x] Восстановить действительно потерянные метаданные старого импорта из неизменённого XLSX, сохранив резервные копии БД.
- [x] Подтвердить, что назначения строк, группы, статусы, этап и расходы остались прежними.
- [x] Добавить тесты аудита, восстановления и запрета автоматического исправления конфликтов ИНН.
- [ ] Если старое исследование будет продолжено: вручную установить опорные ресурсы для четырёх строк с повреждёнными адресами сайтов. В XLSX эти адреса уже содержат символы замены; корпоративных соцссылок в соответствующих полях нет.
- [ ] Перед утверждением точности группировки как измеренного показателя разметить независимую выборку компаний. Внутренняя согласованность сайта, названия и ИНН не заменяет проверку фактической принадлежности ресурса.

## Подтверждённые результаты на большом запуске

- 9 135 исходных строк, 9 135 сохранённых строк, 7 675 предварительных компаний. Контрольные суммы всех строк совпали с исходным XLSX; старый формат контрольной суммы поддержан аудитом.
- 867 групп содержат несколько строк. В исходной базе нет групп с разными заполненными ИНН или названиями и нет строк, чей нормализованный сайт расходится с опорным сайтом группы. Нет групп с несколькими непустыми различающимися описаниями.
- В старом импорте отсутствовали ИНН у 7 656 групп и 1 334 уникальные корпоративные соцссылки у 208 групп. Это исправлено из исходного XLSX. Ни у одной из 208 групп ещё не было сохранённого плана сбора источников.
- Четыре строки остаются без пригодного ресурса: адрес сайта уже повреждён в XLSX, соответствующие корпоративные соцссылки отсутствуют. Статус проверки для них корректен.
- Сравнение БД с резервными копиями подтвердило неизменность состава групп, назначений строк, статуса запуска и расходов. Платные операции не запускались.
