# Проверка стоимости и скорости — 9 октября 2026

Исследование оставлено на паузе. Новые платные запросы не выполнялись. Аудит использует сохранённые ответы и журнал, прямое HTTP-чтение пяти исходных ресурсов и отдельный локальный эксперимент.

## Сохранённый прогон

- В базе 7 675 компаний, 9 135 контактных строк.
- 27 компаний дошли до PROFILE_READY: 22 с подтверждённой идентификацией и 5 с отклонённой. Ещё одна компания частично исследована. Четыре записи без исходного ресурса также требуют проверки, но не входят в эти 27.
- 17 из 22 подтверждённых профилей имеют минимум два confirmed HIGH/MEDIUM признака. Это не проверка независимости и не гарантия валидного сегмента.
- 102 сохранённые страницы, 97 уникальных URL. Только устранение точных повторов URL не даст десятикратной экономии.
- 52 направления COMPLETE, 43 NO_RESULTS, 17 UNAVAILABLE, 5 IDENTITY_REJECTED, одно DISCOVERED.
- 12 доказательств отклонены из-за несовпадения цитаты с переданным текстом. Доля от всех возвращённых моделью доказательств отдельно не вычислялась.
- Ошибки сбора: 12 HTTP 425, 11 запретов robots.txt, 8 таймаутов, 4 HTTP 403 и другие. Блокировки и сертификаты не обходились.

Итого оценка $1,9058. Поисковых tool-вызовов — 135: один запрос к модели не обязательно равен одной оплачиваемой поисковой операции. Совокупное время API-вызовов около 38 минут. Последовательное ожидание является основным ограничением скорости. Время загрузки страниц в эту сумму не входит.

**Ошибка интерпретации цены:** код умножает стоимость входных токенов на 2, выходных на 1,5. Эти коэффициенты перенесены из консервативного резерва в счётчик расходов. Значение нельзя считать точным биллингом. При тех же базовых тарифах без коэффициентов получится около $1,6500 до учёта кэширования и особенностей тарифа; это сценарный перерасчёт, не счёт провайдера. Экстраполяция стоимости всей базы ненадёжна по такой маленькой последовательной выборке.

## Проверка исходных сайтов

Пять ресурсов с IDENTITY_REJECTED проверены текущим HTTP-сборщиком в три потока. Один вернул 3 097 символов, три не разрешились через DNS, один не дал достаточного текста. Общая длительность 2,84 с. Это маленький тест доступности, не тест полной идентификации; доступность сайта сама по себе не подтверждает принадлежность юрлицу.

## Приоритет изменений

1. Читать исходный сайт до платного поиска. Из HTML собирать официальные ссылки, контакты и страницы продуктов. Проверять принадлежность по этим данным, не полагаться исключительно на поисковую выдачу.
2. Объединить первичный поиск источников по направлениям. Дополнительный поиск направлять на конкретные пробелы. Сохранять охват сайта, соцсетей, отзывов, вакансий/новостей и форумов.
3. Кэшировать robots.txt и загрузки по URL, переиспользовать категорийные исследования. Категорийный факт не считать фактом компании.
4. Ввести очередь на 3–4 одновременно обрабатываемые компании с отдельными состояниями и клиентами, ограничениями нагрузки на домен и API, корректной паузой. Не делить один Gateway между потоками. Ускорение требует реального контрольного замера, линейные 4x не гарантированы.
5. Исправить учёт: хранить точное usage, cached tokens, тариф и дату тарифа отдельно от резерва. Сверять с биллингом.
6. Локальную модель использовать сначала для узкого извлечения и нормализации. Строгая проверка JSON и дословных цитат обязательна; семантическая проверка нужна отдельно.

## Бесплатные варианты

- Локальная Qwen3 4B Q4_K_M: файл около 2,5 ГБ, Apache 2.0. На этом компьютере i5-11400H, 16 ГБ RAM и RTX 3060 Laptop 6 ГБ. Тестируется через отдельный Ollama на localhost:11435. Нет оплаты за токены, но есть затраты времени, памяти и электричества. Интернет-поиск модель не заменяет. https://ollama.com/library/qwen3:4b
- Gemini API: у отдельных моделей есть бесплатный ввод/вывод, ограничения зависят от модели и аккаунта. Например у Gemini 3 Flash бесплатный API grounding с Google Search недоступен. В бесплатном уровне документация отмечает использование контента для улучшения продуктов. Секретные офферы и базу контактов туда не отправляли. https://ai.google.dev/gemini-api/docs/pricing
- OpenRouter free: есть ограничения запросов в минуту/сутки и ограничения провайдеров. Подходит для эксперимента, но нельзя рассчитывать на стабильный бесплатный поток для всей базы. Точные лимиты следует получать для конкретного аккаунта. https://openrouter.ai/docs/api_reference/limits

## Критерии следующего сравнительного теста

Одинаковые 20–30 компаний разных типов, одинаковые офферы и требования к evidence. Сравнивать стоимость полезного профиля, полноту направлений, правильность идентификации, точность цитат и интерпретации, независимость подтверждений, медиану и p95 времени. Сохранённую облачную выдачу не считать эталоном без ручной проверки. Внешние бесплатные API в текущем тесте не вызывались.

## Результат локального теста Qwen3 4B

Три первые доступные сохранённые страницы website, 2 555–6 687 символов. Схема ResearchReport, temperature=0, контекст 8 192, максимум 1 500 выходных токенов, до трёх evidence/signals. Офферы не передавались: проверялось узкое извлечение, а не качество оффер-ориентированного исследования. Поэтому это не прямое A/B-сравнение с облачным конвейером.

Модель поместилась в GPU, Ollama сообщил размещение около 5,08 ГБ модели/контекста в видеопамяти. Получилось 8 из 9 точных цитат. Однако во всех девяти evidence модель указала 2026-10-09 как published_at. В первых двух отчётах она одновременно написала, что даты публикации отсутствуют. Это явная семантическая ошибка, которую проверка JSON и точных цитат не обнаруживает. У третьей страницы есть дата состояния каталога; она не подтверждает дату публикации каждого процитированного утверждения.

Также отсутствие подробностей местами попало в contradictions, хотя должно попадать в limitations. Нужны отдельная валидация дат и различение отсутствующих данных и опровержений. Локальную модель пока нельзя делать основным исследователем. Подходящий следующий тест — узкие задания с идентификаторами заранее выделенных фрагментов, null по умолчанию для даты и ручной эталонной разметкой.

Локальный тест не показал ускорения по сравнению с наблюдаемой медианой облачного извлечения 12,92 с, но входы/выходы различаются, поэтому полноценного сравнительного вывода нет. API-плата за локальные тесты отсутствует. Была загружена модель 2,5 ГБ в /tmp/outreach-model-test; основной конвейер не переключался на неё.

41 существующий автоматический тест приложения прошёл. Они проверяют механику, но не доказывают качество модели. Автоматическое наблюдение остановлено по запросу пользователя.
