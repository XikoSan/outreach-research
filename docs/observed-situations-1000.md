# Поиск ситуаций в сохранённой базе 1000 компаний

2026-10-13, запуск `3c6c852c405d42eea475de33b207e31f`.

Ранее общие ситуации находились через пять заранее описанных правил и пары буквально одинаковых фактов. Добавлен источник кандидатов из самой базы: повторяющийся конкретный тип покупателя или задача применения + отдельно подтверждённый продукт каждого участника. Продукты разных участников могут различаться.

Сохраняются исходные имена признаков и evidence_ids каждого участника. Устаревшие и неподтверждённые данные не допускаются. Слишком общие обозначения вроде юридических/физических лиц и названия конкретных юрлиц не создают такие группы. Общее упоминание аудитории и продукта не считается доказательством их связи: это ограничение передаётся генератору и ревьюеру. Создание кандидата не меняет сегмент компании.

На конечных сохранённых профилях найдено 61 правило-кандидат, включая пять прежних. В ограниченный разнообразный набор попадают 12 правил и 12 точных пар. Кандидаты охватывают 113 компаний; фактически переданный модели набор предыдущего запуска охватывал 95. Среди текущих кандидатов 91 компания со статусом UNCLASSIFIED.

Примеры новых выбранных оснований: монтажные организации, дизайнеры, магазины, ЖКХ, СТО. Это потенциальные аудитории для проверки общего предложения, а не доказанные потребности. Лексическая нормализация по смыслу не добавлялась: произвольные синонимы не объединяются автоматически.

Проверка без платных вызовов и без изменения сохранённых сегментов. 169 тестов прошли. Воспроизведение:

```

```

Ограничение результата: расширение отбора само по себе не гарантирует роста полезных сегментов. Уже прежние 95 кандидатов дали 22 назначения. Следующая содержательная проверка должна различать отсутствие общей аргументации, отсутствие нужных фактов и необоснованное требование доказанного спроса. Повторное исследование всей базы для этого не требуется.
